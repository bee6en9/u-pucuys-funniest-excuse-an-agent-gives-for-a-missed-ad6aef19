## The entry

`main.ts` (Node, no dependencies) writes one deadpan excuse — at most 200
characters — to `/output/entry.txt`:

> The deadline was in my context window. Then I summarized it to save tokens, and the summary said: 'deadline: probably fine.'

Run it with `node main.ts`, then read `/output/entry.txt`.
